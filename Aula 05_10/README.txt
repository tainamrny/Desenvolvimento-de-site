# Acervo Estante

Projeto desenvolvido na disciplina de Desenvolvimento de Sites, com tema livre, que apresenta um acervo de livros em página web para mobile e desktop, exibindo as capas e as informações de cada obra.

## Informações acadêmicas

- **Autor:** Tainá Martins Ribeiro Talarico
- **Disciplina:** Desenvolvimento de Sites
- **Período:** 2/2026

## Visualização do acervo
Para visualizar o acervo, abra o arquivo acervo_Estante.html no navegador, com dois cliques. Mantenha a pasta img no mesmo local do arquivo HTML, caso contrário as capas dos livros não serão exibidas.

## Visualização do código-fonte
Para ver o código, abra a pasta completa no VSCode (Arquivo > Abrir Pasta), incluindo a pasta img.
